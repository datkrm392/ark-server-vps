## 方舟这游戏，先卡内存再卡 CPU

方舟是出了名的配置杀手，但它的"吃配置"和 Minecraft 不太一样。Minecraft 装一百个模组，内存吃掉的是模组本身；方舟光是**单张地图跑起来，服务端基础占用就有 4–6GB**，客户端的恐龙、建筑、掉落物越多，这个数字只会往上走。

第三方实测给出的参考区间是这样：

| 同时在线人数 | 内存占用 | 建议配置 | 备注 |
| --- | --- | --- | --- |
| 2–4 人 | 约 6–8GB | 2–4 核 / 8G | 单张地图，不开太多 MOD |
| 5–10 人 | 约 10–14GB | 4–8 核 / 16G | 建议 SSD 80G 以上 |
| 10 人以上 | 16GB 起 | 8 核以上 / 32G | 多地图、多 MOD 场景 |

开服社区里流传的一套硬件基线也差不多：CPU 最低 2 核、推荐 4 核、想流畅给 8 核；内存最低 6G、推荐 8G、流畅 16G；硬盘最低 50G、推荐 100G，另外还要额外准备 4G 虚拟内存。

> 常见误判：以为卡顿是带宽不够。方舟真正先撑不住的是内存和 CPU 单核性能，10–15Mbps 上行对十几个人来说通常已经够了，堆带宽解决不了服务器崩服。

还有两个容易被忽略的点：

- **服务端本体就要约 18GB**（Steam app ID `376030`），加上存档和地图，50G 硬盘属于勉强，100G 才舒服。
- **存档只会越来越大**。开了几个月的服，存档体积翻倍很正常，这也是为什么长期服最好直接给足硬盘余量，而不是等满了再迁移。

## 从买机器到朋友进服，实际要走这几步

以雨云 VPS 路线为例，整条链路是这样的：

1. **选地区和机型**。玩家集中在哪就选哪，雨云国内节点覆盖江苏宿迁、江苏镇江、浙江宁波、浙江温州、湖北十堰等地。评测数据显示国内 BGP 节点三网平均延迟在 29–35ms 区间，国内队伍基本够用。
2. **选系统**。Linux（Ubuntu / Debian）跑方舟服务端更省资源，Windows 适合完全不想碰命令行的人，但内存占用更高。
3. **装 SteamCMD**。用官方源或者 Docker 镜像都行，社区有现成的一键部署镜像（如 `expm02/ark-server-docker`）。
4. **下载服务端**：`app_update 376030`，约 18GB。这一步在国内节点会比较慢，可能反复失败，重新执行会断点续传。
5. **改端口和参数**。默认端口组是 7777（游戏）、7778、27015（查询）。你要在雨云控制台把这几个 UDP 端口放行——15 个自定义端口额度完全够用。
6. **设好虚拟内存**。建议 4G，方舟在内存吃紧时会靠它兜底，不然容易直接崩服。
7. **客户端连接**。Steam 里用 `open IP:端口` 进服，或者把服务器加进收藏。

如果是在自己电脑上开，还要额外搞定路由器端口映射和公网 IP 问题，这也是很多人绕一圈又回来租服务器的原因。

## 选配置时最容易漏掉的四件事

**硬盘扩容单价按地区不同。** 宿迁大约 1 元/GB/月，温州约 0.65 元/GB/月。方舟服务端 18GB + 存档，30G+20G 的默认盘跑一段时间就会紧张，买之前先算一下要不要加盘。

**带宽也是按档加价的。** 以镇江机型为例，每加 5Mbps 上行约 25 元/月。但实际上十几人的方舟服 10–15Mbps 上行通常够用，这笔钱多数人不用花。

**NAT 模式和独立 IP 的取舍。** 默认的 NAT 机型是共用公网 IP，靠端口映射对外提供服务，方舟这种直连 IP:端口的方式完全兼容，能正常玩。想要更干净的独立 IP 可以加购：宁波的 100G 高防 IP 约 30 元/月，镇江的 200G 高防 IP 约 200 元/个——不同地区、不同防御规格差得很多，别默认价格一样。如果服务器对外公开、可能有被攻击的风险，独立 IP + 高防的优势才明显。

**先试再买。** 雨云支持 1 元试用一天（每款机型限一次，较贵产品试用价会高一些），也支持 7 天无理由退订（每账号限 3 次）。方舟服务端下载就要 18GB，试用的价值主要在于先测一下延迟和下载速度，确认合适再决定长期方案。

## 常见问题

**2 核 4G 能开方舟吗？**
能开起来，但基本只能 2–3 人、单张地图、不装 MOD，而且玩家一多就会开始掉 TPS。方舟的内存基线比 MC 高得多，这个配置在方舟上属于"能跑但不建议长期用"。

**一定要买独立 IP 吗？**
不一定。NAT 模式靠端口映射一样能连，方舟用 IP:端口直连本来就是标准玩法。只有当你需要对外公开、担心被攻击，或者不想和其他用户共用 IP 时才值得加钱。

**用香港节点会不会更好？**
香港节点的优势在海外下载快、不被墙拦，这一点在下载那 18GB 服务端时确实明显。但如果玩家全在国内，游戏过程中的延迟还是国内 BGP 节点更稳。两边都要兼顾的话，可以考虑服务端在国内节点、首次下载时临时借道海外线路。

**方舟官方服务器还能用吗？**
不能了。ARK: Survival Evolved 的官方免费服务器 2023 年已关闭，现在只有非专用服务器（自己当主机）和专用服务器（自建或租用）两种选择。另外要注意，重制版 ARK: Survival Ascended 是另一套服务端，目前的租服模板和配置建议基本都是针对 ASE 的，两边的存档不通用。

**雨云的面板服能开方舟吗？**
雨云的产品线里，面板类产品（雨云面板、MCSM 面板）定位是"一键开服、适合单端场景"，主要面向 Minecraft 这类有成熟面板模板的生态，预装软件里也是 MCSM、Java 环境这些。方舟走的是 SteamCMD 路线，需要自己装环境、改 ini、管端口，所以选 VPS 那一条线更顺。
